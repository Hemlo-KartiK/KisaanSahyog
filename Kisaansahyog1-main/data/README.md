# KisaanSahyog — Knowledge Base & Mock Datasets

This directory will hold curated content for the project.

## Planned structure
- `crops/` — Crop calendars, varieties, pest guides
- `mandi/` — Mandi price snapshots for testing
- `soil/` — Soil Health Card templates and lookup tables
- `kvk/` — KVK directory by district/state
- `lessons/` — Skill library content (maps to `packages/skills`)
- `weather/` — Offline forecast samples

## Phase 1
A placeholder marker is included so the directory is tracked by version control. Real JSON datasets will be added in Phases 5, 7, 9, and 13.
